# Planted by Strangers

A garden where every flower is a real person. Comment a name on the latest
video, tell us why if you like, and tomorrow it blooms.

| Path | Content |
|---|---|
| `reels/day-NNN.mp4` | the daily episodes, published through Buffer via the raw URL |
| `garden.json` | every flower that has been planted (number, name, day) |
| `brand/` | profile picture, banner, watermark |

Buffer fetches the videos from
`https://raw.githubusercontent.com/pascdj89/plantedbystrangers/main/reels/day-NNN.mp4`.
Do not rename or move a file while a scheduled post points to it. No force-push.
